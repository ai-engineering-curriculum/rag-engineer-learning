| `ai-eval-engineer-learning` | 30 | "RAG Evaluation at the Application Layer" — RAGAS / TruLens / DeepEval, faithfulness / context precision-recall, distractor suites | Retriever tuning, reranker choice, embedding-model selection, chunker design, hybrid retrieval |
| `agentic-ai-engineer-learning` | 40 | Agent orchestration and tool-use planning that CONSUMES retrievers | Exposing a retriever as an MCP-compatible / function-calling tool (owned here in mod-110) |
| `fine-tuning-engineer-learning` | 30 | Embedding SFT / LoRA / PEFT training craft (sentence-transformers TSDAE, MultipleNegativesRankingLoss) | Embedding selection, benchmarking, domain-fit — owned here in mod-103 |
| `ai-risk-engineer-learning` | 25 | Content-safety, PII redaction, guardrail-effectiveness methodology | ACL-aware retrieval MECHANICS (owned here in mod-112) |

Therefore this track (`rag-engineer-learning`, level 30, peer) owns:

- Retrieval **engineering** (not consumption): chunking, embeddings, vector-DB internals, Lucene-family engines, hybrid search, ANN tuning, index versioning
- **Retrieval-specific** evaluation (recall@k, MRR, nDCG, hit-rate) — NOT the RAG-triad or application-layer eval
- **Retrieval-specific** observability (per-chunk provenance, retriever hit-rate telemetry) — NOT general LLM tracing
- **Retrieval-specific** prompt patterns (citation instruction, refusal-when-no-context, contradiction handling) — NOT general prompt engineering
- **Exposing** a retriever as a tool (MCP, function-calling) — NOT general agent orchestration

## Delta rationale (this cycle)

See [`.aicg/curriculum-plan-delta.json`](.aicg/curriculum-plan-delta.json). This cycle proposes **zero new modules, exercises, or projects**. Reasoning:

1. **The curriculum remains mature and fully authored.** Every requirement rated above the 0.30 in-window frequency threshold is already covered by an authored module with real chapters, exercises, and labs. This cycle's role in the org loop is to *confirm ownership boundaries, update coverage links, and reassess the emerging-signal watchlist* — not to seed content.
2. **Live-web / agentic-search retrieval infrastructure (row 23) is the one signal that genuinely strengthened** — from 2 postings / 0.07 (2026-09) to 7 postings / 0.25 (2026-10), across 5 distinct employers. Firecrawl's Web Automation Engineer JD newly names anti-bot / fingerprinting evasion as a core retrieval-infra responsibility, a sub-signal that did not surface last cycle. **The 3-posting evidence bar is now cleared firmly.** However:
    - The 0.25 observed frequency reflects a deliberately infra-weighted sample this cycle. In the balanced 2026-09 sample composition, these 7 postings would represent roughly 4 postings (removing double-count of Firecrawl's dual role + Perplexity's dual role) at ~0.14–0.18 frequency — **still below the 0.30 threshold**.
    - Per the continuity-bias directive, net-new content requires ALL of (≥ 3 postings AND ≥ 0.30 frequency AND no incrementally-extendable existing coverage). Frequency does not cleanly hold.
    - Live-web is a distinct engineering surface — mod-102 covers static-corpus ingestion (unstructured.io, Docling, OCR fallback), mod-112 covers enterprise structured / graph / multimodal. Neither can be incrementally extended to cover crawl orchestration, headless-browser rendering, freshness SLAs, or anti-bot resilience. So if frequency crosses 0.30 next cycle, the right delta shape is a **new mod-113**, not an exercise appended to an existing module.
3. **MCP-server exposure (row 16) and query rewriting (row 14) both rose but remain sub-threshold** at 0.25 and 0.29 respectively. Both are already OWNED (mod-110, mod-106). No delta action needed.
4. **Infra-side frequencies that rose (freshness SLAs in row 8, petabyte-scale indexing in row 13)** map cleanly to existing content — mod-111 drift/freshness and mod-104 ANN tuning. No delta action needed.
5. **Consumer-side frequency drops (rows 1, 2, 3)** are **sample-composition artifacts**, not real market retreat. This cycle under-sampled RAG-product-builder roles to reassess the infra watchlist. Next cycle should resample with the balanced composition that governed 2026-08 and 2026-09.
